Admin Reports

/superadmin/reports

Platform-wide, cross-tenant reporting. All numbers ignore the per-company data filter so they span every tenant. Four tabs: Dashboard, Packages, Balances, Usage.

Key concept — "Billable": WhatsApp charges per message/conversation. Each outbound message is flagged Billable = true when it counts against paid usage (a service/marketing message that WhatsApp bills for). Free-tier or non-chargeable sends are Billable = false. So Total Billable = the number of outbound messages you can actually bill the customer for, which is usually less than Total Sent.

Tab: Dashboard — the 8 KPI cards

CardMeaningHow it's computed
Total CompaniesEvery tenant on the platform, active or not.Count of all rows in Companies.
Active CompaniesTenants that are enabled (not deactivated).Count of Companies where IsActive = true.
Active SubscriptionsCompanies currently on a live paid plan.Count of subscriptions where IsActive and Status = Active.
Packages Sold (mo)New plan purchases this calendar month.Count of subscriptions with CreatedAt ≥ 1st of this month. Every subscription created = one purchase.
Revenue (mo)Estimated revenue booked this month.Sum of the Plan.Price of every subscription created this month. (Derived from plan price — Stripe isn't live yet, so this is list-price, not collected cash.)
New Signups (mo)Companies that joined this month.Count of Companies with CreatedAt ≥ 1st of this month.
Messages Sent (30d)Outbound message volume, last 30 days.Count of Messages where Direction = Outbound and CreatedAt ≥ now − 30 days.
Low Balance CompaniesTenants about to run out of message quota.Count of active subscriptions whose Remaining < 10% of effective quota. Turns amber when > 0.

Note: the DTO also carries Billable Messages (30d), but the dashboard grid currently renders 8 cards and doesn't surface it.

Tab: Packages — purchases by date range

Filterable by date range (default: last 30 days). Two summary cards + a per-plan table.

FieldMeaning
Total PackagesCount of all subscriptions created inside the selected range (each = one package purchased).
Total RevenueSum of plan price × purchases across all plans in the range.
PlanPlan name. Shows (deleted plan) if the plan was later removed but the purchase still happened.
PriceCurrent list price of that plan, in its currency.
PackagesHow many times that plan was purchased in the range.
RevenuePrice × Packages for that plan.
ShareBar showing that plan's revenue relative to the top-earning plan.

Tab: Balances — remaining quota per company

One row per active subscription. Low-balance rows are highlighted amber and sorted to the top. No date filter (it's a live snapshot).

ColumnMeaning
CompanyTenant name. Amber ⚠ icon if it's low on balance.
PlanThe plan the company is subscribed to.
QuotaEffective quota = plan monthly quota + purchased extra credits.
UsedMessages consumed in the current billing period (MessagesUsedThisPeriod).
RemainingQuota − Used. Shown amber when low, otherwise orange.
UsageProgress bar of Used / Quota.
Period EndsWhen the current billing period resets (CurrentPeriodEnd).
Low balance rule: a company is flagged when Remaining < 10% of Quota (and quota > 0). This is the same rule that feeds the "Low Balance Companies" dashboard card.

Tab: Usage — message analytics per company

Filterable by date range. Two summary cards + a per-company breakdown, sorted by most sent. Counts outbound messages only.

ColumnMeaning
Total SentAll outbound messages across all tenants in the range.
Total BillableOf those, how many are chargeable (Billable = true) — the ones you actually bill for.
CompanyTenant name.
SentOutbound messages this company sent in the range.
DeliveredOf those, how many reached the handset (Status = Delivered).
ReadHow many were opened/read by the recipient (Status = Read).
FailedHow many failed to send (Status = Failed) — shown in red.
BillableHow many of this company's sends were chargeable.

Delivered/Read/Failed are message statuses, so they don't have to add up to Sent (some are still "sent/pending"). Every tab is exportable to CSV.

Companies

/superadmin/companies

The master tenant list — every business using the platform. Create, edit, activate/deactivate. (There is no hard delete from the UI.)

FieldMeaning
NameCompany / tenant display name.
SlugURL-safe short identifier for the company.
EmailPrimary contact email for the company.
PhoneContact phone number.
Active statusWhether the tenant is enabled. Deactivating blocks its users from working without deleting data.
Created AtWhen the company was onboarded.

WABA Connections

/superadmin/waba-connections

WhatsApp Business Account links per company — the phone numbers each tenant sends from and their Meta credentials.

FieldMeaning
CompanyWhich tenant this WhatsApp number belongs to.
Display Phone NumberThe human-readable sending number (e.g. +971…).
Phone Number IDMeta's internal ID for the number — used in API calls to send messages.
WABA IDThe WhatsApp Business Account ID from Meta.
Status enumConnection health with Meta (e.g. connected / pending / disconnected).
Has Access TokenWhether a valid Meta access token is stored (needed to actually send). The token itself is never shown.
ActiveWhether this connection is enabled for sending.
Created AtWhen the connection was added.

Plans

/superadmin/plans

The recurring subscription tiers you sell. A company subscribes to exactly one plan, which sets its monthly message allowance.

FieldMeaning
NamePlan tier name (e.g. Starter, Pro).
Monthly Message QuotaMessages included per billing period. Feeds "Quota" on the Balances report.
PriceRecurring price of the plan.
CurrencyCurrency the price is in (e.g. USD, AED).
Feature FlagsList of capabilities the plan unlocks.
ActiveWhether the plan can be newly subscribed to.
Created AtWhen the plan was created.

Packages

/superadmin/packages

One-off message-credit top-ups. Unlike plans, these are bought as needed to add extra messages on top of the plan quota (the "extra credits" in Balances).

FieldMeaning
NamePackage name (e.g. "10k Messages").
DescriptionOptional detail about the package.
Extra MessagesHow many message credits this package adds to a company's balance.
PriceOne-time price of the top-up.
CurrencyCurrency of the price.
ActiveWhether the package is available for purchase.
Created AtWhen the package was created.

Subscriptions

The live link between a company and its plan — current status, quota, and consumption. Also tracks package-purchase history.

FieldMeaning
CompanyThe subscribed tenant.
PlanThe plan they're on.
Status enumActive · Inactive · Trialing · Cancelled.
Monthly Message QuotaBase allowance from the plan.
Extra Message CreditsCredits added from purchased packages.
Effective Message QuotaMonthly quota + extra credits — the real usable total.
Messages Used This PeriodConsumed so far this billing period.
Messages RemainingEffective quota − used.
Current Period Start / EndThe active billing window; usage resets at period end.
Has SubscriptionWhether the company has any subscription at all (vs. none).

Package purchase history (per subscription)

FieldMeaning

Monitoring

/superadmin/monitoring

Per-company health for the last 30 days — designed to spot tenants at risk of a WhatsApp ban (high failure rates, quality drops).

FieldMeaning
CompanyTenant name, plus active/inactive.
Total Sent (30d)Outbound messages in the last 30 days.
Failed (30d)How many failed in that window.
Billable (30d)Chargeable sends in that window.
Failure RateFailed / Sent. High rates risk account bans.
FlaggedTrue when the failure rate crosses the risk threshold — needs attention.
Active CampaignsCampaigns currently running for the company.
Last Message AtWhen the company last sent anything.
Quality RatingMeta's quality rating for the number (Green / Yellow / Red), if available.

Server Logs

/superadmin/server-logs

A live viewer streaming the backend's log output — for debugging in real time. Auto-scroll is off by default and the view is capped at the latest 100 entries.

Each entry: timestamp · level (Info/Warn/Error) · message Use it for: watching webhook + campaign activity as it happens
